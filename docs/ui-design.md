# UI 设计说明

## 设计方向

**中性灰画布 + 纯白卡片 + 蓝色作为唯一交互强调色。**

参考了营养/健康类仪表盘的排版方式：信息按行对齐、卡片高度一致、数字优先。整体不是“炫技式 AI 视觉”，而是一套安静、工整的家庭媒体工具后台。

- 页面背景使用中性灰，内容区是纯白色块
- 蓝色只用于选中态、主操作、数据强调和图表
- 不使用紫色、高饱和渐变或大面积彩色光斑
- 按钮使用液态玻璃质感：多层渐变 + 内侧高光 + 细边框
- 所有卡片按行对齐，不允许出现某张卡片提前结束、右侧留下大块空白

## 关键布局

### 仪表盘

仪表盘按行组织，每一行内的卡片等高：

1. **统计行**：播放记录 / 已看完 / 已同步 / 待处理，四等分。
2. **内容行**：电影 / 剧集 / 看得最多的剧，三等分。电影和剧集直接展示“多少部”的大数字，再拆出播放、已看完、已同步三个小指标，和播放记录的统计格式保持一致。
3. **趋势行**：最近 30 天趋势（约 2/3）+ 同步状态分布（约 1/3）。
4. **明细行**：最近观看（约 2/3）+ 最近同步（约 1/3）。

网格使用 `minmax(0, 1fr)` 和 `align-items: stretch`，右侧短卡片会被拉伸到与左侧同高，避免出现“左卡片结束后下面空一大块”的情况。移动端按行折叠成单列。

### 顶部提示

仪表盘的未绑定 / 未读取提示不再使用琥珀色 `el-alert`，改为白色卡片 + 淡蓝渐变 + 蓝色图标块，与整体色板一致。

### 侧边栏

- 白色圆角卡片，与页面边缘留 14px
- 菜单容器是浅灰圆角块，选中项变成白色药丸
- 选中项的文字保持深色，只把图标染成蓝色，形成“蓝色图标 = 选中”的标记
- 不再使用左侧色条和蓝色发光

### 顶栏

- 独立的白色圆角卡片，`sticky` 悬浮
- 高度 60px，圆角 14px，细边框 + 轻阴影
- 与内容之间保留 14px 间距，顶部不再出现整块白色横条

### 卡片

- 统一 20px 圆角
- 纯白背景（暗黑为 `#141a24`）
- 1px 低对比边框 + 柔和阴影
- 不再对内容卡片使用 backdrop blur，保证文字清晰、滚动流畅

### 按钮

参考 [liquid-glass-react](https://github.com/rdev/liquid-glass-react) 的视觉思路，但用纯 CSS 实现：

- 主按钮：蓝色纵向渐变 + 顶部白色反光 + 内侧四边高光 + 底部内阴影
- 次按钮：白色到浅灰的纵向渐变 + 1px 白色内边框 + 外圈细描边
- hover 时轻微上浮、亮度提高，active 回弹
- 不使用 `backdrop-filter: url(...)` 的 SVG 位移滤镜，避免部分 Chromium 环境下按钮内容不绘制的问题

### 表格

- 表头透明、灰色小字，底部一条细分割线
- 行高 52–56px，行间使用极淡分割线
- 行悬浮使用浅灰底
- 移动端隐藏次要列，固定媒体 / 状态 / 操作三列
- 底部分页在移动端隐藏页容量和跳页，只保留上一页 / 页码 / 下一页

### 渐变的使用

渐变只出现在这些位置，避免“到处发光”：

- 主按钮的玻璃高光
- 进度条、排行的蓝色横向渐变
- 图表柱状图的蓝色纵向渐变
- 顶部提示卡片的淡蓝渐变
- 页面背景顶部一层几乎不可见的冷灰径向渐变

## 主题切换

- 右上角分段按钮：太阳 / 月亮
- 首次访问读取 `prefers-color-scheme`
- 手动选择写入 `localStorage` 的 `fn2t-theme`
- 切换时同步更新 `<html data-theme="...">` 和 Element Plus 的 `dark` class
- 图表颜色会随主题重新计算

## 响应式

- `> 1180px`：仪表盘三列内容行、2/3 + 1/3 的图表与明细行
- `900–1180px`：内容行两列，第三张卡片跨整行；图表和明细改为单列
- `< 900px`：侧边栏变为抽屉，顶栏收起连接状态和用户名
- `< 720px`：统计卡两列，其余卡片单列；表格隐藏进度 / 匹配列，筛选器纵向堆叠
